# Walmart Retail Sales Analysis

An end-to-end retail data analytics project focused on analyzing Walmart sales performance across stores, departments, store types, and time periods.

## Project Overview

This project transforms raw Walmart retail sales data into actionable business insights using Excel, SQL, Python, and Power BI.

The analysis focuses on:

- Store-level sales performance
- Department-level performance
- Sales trends and seasonality
- Holiday vs non-holiday sales
- Store size and sales relationship
- Performance ranking of stores and departments
- Identification of sales exceptions

## Key Results

- **421,570** sales records analyzed
- **45** stores analyzed
- **81** departments analyzed
- **$6.74B** total sales analyzed
- **$15.98K** average weekly sales
- **$17.04K** average holiday sales

## Dashboard

The Power BI dashboard contains four analytical pages:

1. **Executive Overview**
2. **Store Performance**
3. **Department Analysis**
4. **Sales & Seasonality**

## Key Business Insights

- Store performance varies significantly across locations.
- Larger stores generally generate higher sales.
- Sales show clear seasonal patterns.
- Holiday weeks show higher average sales than non-holiday weeks.
- Negative sales records require monitoring and further investigation.

## Project Outcome

The project demonstrates an end-to-end analytics workflow that converts raw retail data into structured analysis, interactive dashboards, and business-focused insights.
